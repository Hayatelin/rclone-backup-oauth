Privacy Policy for rclone-backup

Last updated: October 2, 2026

Who uses this app

rclone-backup is a personal OAuth client used only by its developer (GitHub: Hayatelin) with his own Google account. It is not offered to the public.

What data it accesses

The app uses the Google Drive API only to copy the developer's own files from his own computer to his own Google Drive, using rclone. It does not access any other user's Google account or data.

How data is stored and shared

The app does not collect, store, sell or share personal data of any other person. OAuth tokens are stored only in the rclone configuration file on the developer's own computer and are never sent to any third party or to any server run by the developer.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
